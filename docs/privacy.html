Who processes what

  • Local use (default). DeGoogle Kit runs on your Windows PC. Plan, checklist, scan results, Takeout files you choose, API keys, and trial/Pro status stay in AppData\DeGoogleKit. Opolyonix Corp does not receive that copy unless you later choose an optional cloud feature.
  • Shared free account (website + Windows app). One Supabase project (degoogle). The same email/password works in both places. We store your email, a hashed password, your plan, your guide checklist, trial start time, linked license, household invites, and support messages. Export and delete use the same database functions on the website account page and in the app (Privacy).
  • Household invites. If you buy Household, you may invite other emails from the website. We store invite email, status, hashed login codes, and PC-claim hashes. Unclaimed invitees do not receive the license key or the owner’s plan backup.
  • Payments. Stripe processes Checkout for Lifetime Pro / Household (Family). We do not store card numbers. After payment a signed license key can be linked to your account.
  • Updates and this website. GitHub (Microsoft) hosts the Windows download, version feed, and these pages. Checking for updates is optional and sends the app version in the User-Agent.
  • Optional Cloud AI. Only if you tick a separate consent box. Ask AI with your own key sends the question and a local scan summary to the provider you pick (never Google Gemini). DeGoogle AI (Cloud Pass) sends the same kind of payload to our license server, which then calls Groq (GPT-OSS 120B) — we pay Groq; the key never sits in this app. We do not log the question. You can withdraw that consent in the app.
