# DeGoogle Kit

Windows app to leave Google on your terms: scan this PC, pick replacements, parse Takeout locally, then disconnect. It never auto-deletes Google.

## Download for Windows

**[DeGoogleKit-win-x64.zip](https://github.com/OpolyCorporation/degoogle-kit/releases/latest/download/DeGoogleKit-win-x64.zip)** — unzip and run `DeGoogleKit.exe`. You do not need to install .NET.

That same link is what a website should use. It always points at the latest GitHub Release:

```
https://github.com/OpolyCorporation/degoogle-kit/releases/latest/download/DeGoogleKit-win-x64.zip
```

All versions: [Releases](https://github.com/OpolyCorporation/degoogle-kit/releases)

If Windows SmartScreen says the app is unrecognized, choose **More info → Run anyway**. Builds are not code-signed yet.

## Requirements

- Windows 10 or 11, 64-bit
- No installer. No Google account. Checkout (when live) goes through Stripe in the browser.
